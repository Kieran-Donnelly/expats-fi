# Expats.fi SEO crawl baseline

Checked: 8 September 2026  
Scope: every public URL in `https://expats.fi/sitemap.xml`, plus internal links found outside the sitemap

## What is healthy

- All 533 sitemap URLs returned HTTP 200.
- No sitemap URL redirected.
- No sitemap URL was marked `noindex`.
- Every sitemap URL had a title, meta description, canonical URL and one H1.
- Every canonical matched its sitemap URL.
- Titles and descriptions were unique across the sitemap.
- Every image found in rendered HTML had an `alt` attribute.
- No sitemap page was orphaned from the site's rendered internal-link graph.
- The only apparent broken internal URL was Cloudflare's email-obfuscation endpoint. It is not a visitor-facing link and is now excluded from the audit.

## Improvements made from this crawl

- Search descriptions are shortened cleanly at a word boundary instead of sending long editorial summaries to Google. Before the change, 153 pages had descriptions longer than 160 characters and 131 were longer than 180 characters.
- Related news and resource cards now rotate around the current article instead of repeatedly showing the same newest three items. This gives older useful pages meaningful links from their own topic cluster.
- All 197 embassy and official-representation profiles now include breadcrumb structured data.
- A repeatable `npm run audit:seo` crawl is available for launch checks and future maintenance.

## Search Console messages in context

- **Page with redirect:** expected for old URLs, trailing-slash variants or filtered URLs when the destination is correct. There are no redirects inside the current sitemap.
- **Alternative page with proper canonical:** normally informational. There are no canonical mismatches inside the current sitemap.
- **Excluded by `noindex`:** expected for private, account, admin and expired-event journeys. There are no noindexed URLs inside the current sitemap.
- **Not found (404):** old external or removed URLs can remain in Search Console for a while. The live internal-link crawl did not find a genuine public 404.
- **Server error (5xx):** likely historical or intermittent. All 533 sitemap pages completed successfully in this crawl. Inspect the example URLs in Search Console before deciding whether any application fix is needed.

## Ranked SEO queue

1. Use Search Console's example URLs to validate the historical 5xx and 404 groups, then request validation for resolved groups.
2. Build a keyword and search-intent map for the main hubs so closely related pages do not compete with one another.
3. Optimise the highest-value 25 to 40 pages first. Start with moving, permits, first 90 days, housing, work, family, study, Finnish language, Helsinki areas and the business directory.
4. Review long page titles editorially. Google does not impose a fixed character limit, so shorten only where the useful search phrase is buried or the wording is repetitive.
5. Expand contextual links from major hubs and guides into the strongest related pages, using descriptive anchor text.
6. Add visible reviewed or updated dates to high-stakes evergreen guides and schedule regular checks against official sources.
7. Review real Search Console query, page and country data after enough impressions accumulate, then refine titles and introductions based on actual demand rather than guesses.
8. Measure Core Web Vitals on representative hub, article, directory and map-heavy pages and address confirmed field-data problems.

## Content-quality notes

- Embassy profiles are brief by design, but each answers a specific country-level task with unique contact and accreditation information. Do not pad them with generic country copy.
- The community board is the only non-embassy sitemap page below 200 rendered words. It is a functional interface, not a thin article, so word count alone is not a reason to expand it.
- Long news and guide titles are often human and descriptive. Treat display length as an editorial opportunity, not a technical failure.
